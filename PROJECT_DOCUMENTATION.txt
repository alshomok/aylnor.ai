توثيق مشروع AYLNOR.AI

نظرة عامة
----------

المشاكل التي واجهتنا وحلولها
-------------------------------

1. البوت يرد برسائل فارغة
المشكلة: جميع الأوضاع (سريع، مفكر، مبرمج) تُرجع رسائل فارغة

الأسباب المحتملة:
- مفاتيح AI غير مكونة في Environment Variables
- ترتيب المفاتيح يبدأ بـ Gemini بينما مفاتيح Groq فقط متوفرة
- API keys placeholder وليست مفاتيح فعلية

الحل:
1. تعديل ai-key-rotation.ts:
   const MODE_ROTATION_PRIORITIES: Record<BotMode, AIModel[]> = {
     quick: ['model-3', 'model-4', 'model-2', 'model-1'],
     thoughtful: ['model-3', 'model-4', 'model-2', 'model-1'],
     programming: ['model-3', 'model-4', 'model-2', 'model-1'],
   };

2. إضافة المفاتيح في Vercel Environment Variables:
   - GROQ_API_KEY_1
   - GROQ_API_KEY_2
   - GEMINI_API_KEY_1
   - GEMINI_API_KEY_2

3. إضافة logging لتتبع حالة المفاتيح

2. انفصال METADATA عن JSON في الـ Stream
المشكلة: الـ metadata يُرسل في chunk منفصل عن JSON، مما يسبب مشاكل في التحليل

الحل في السيرفر (route.ts):
// دمج في سطر واحد
controller.enqueue(
  encoder.encode(
    '\n\n__METADATA__' + JSON.stringify({
      mode,
      codeBlock,
      fileCard: (isFileRequest && foundFile) ? { ... } : null,
      source,
    })
  )
);

الحل في العميل (ChatMain.tsx):
let metadataReceived = false;

// بعد استلام الميتاداتا
if (fullContent.includes('__METADATA__')) {
  const [contentPart, metadataPart] = fullContent.split('__METADATA__');
  fullContent = contentPart;
  try {
    metadata = JSON.parse(metadataPart.trim());
    metadataReceived = true;
  } catch (e) {
    console.error('Failed to parse metadata:', e);
  }
}

// تخطي التحديث بعد استلام الميتاداتا
if (metadataReceived) {
  continue;
}

3. أخطاء في route.ts
المشكلة: أخطاء syntax في النصوص العربية و template literals

الحل:
- إضافة backticks للنصوص العربية
- إصلاح template literals المكسورة
- إضافة علامات اقتباس للـ URLs

الأدوات والتقنيات المستخدمة
-----------------------------

Frontend
- Next.js 14 (App Router)
- TypeScript
- TailwindCSS
- Lucide React (أيقونات)
- React (Hooks: useState, useEffect, useRef)

Backend
- Next.js API Routes
- Supabase (قاعدة البيانات)
- AI SDK (Vercel AI SDK)
  - Groq (LLM provider)
  - Google Gemini (LLM provider)

AI Providers
- Groq: llama-3.1-8b-instant, gemma2-9b-it
- Google Gemini: gemini-1.5-flash, gemini-2.0-flash

قواعد البيانات (Supabase)
- conversations: تخزين المحادثات
- messages: تخزين الرسائل
- knowledge_base: تخزين الملفات المرفوعة
- educational_files: تخزين الملفات التعليمية من Google Drive

Web Search
- Serper API (للبحث على الإنترنت)
